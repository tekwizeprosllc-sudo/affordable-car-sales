What this costs to run

  • Messenger API — free. Meta charges nothing for webhooks, page tokens, or sending replies. Budget a 24–48 hour app review before it goes live on the real page.
  • Email alerts — free. Send on their own, no one has to be watching the board.
  • Call and text — free, one tap. Opens the dialer or messages app on staff phones with the number and a draft filled in.
  • Automated SMS — about a cent a message. The only paid piece, and only if they want texts that fire with nobody tapping. Most lots don't need it.
